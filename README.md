# Monorepo

A starter with API, web, LINE LIFF, mobile and marketing apps.

## Quick start

```sh
mise install
pnpm install
pnpm --filter api dev
pnpm --filter web dev
```

Run API and web in separate terminals. Open [the notes app](http://localhost:3000) and add a note.

Start `liff`, `mobile` or `marketing` with `pnpm --filter <app> dev`.
