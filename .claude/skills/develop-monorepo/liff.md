# liff

Vite 8, React 19 and TanStack Router, opened inside LINE. `src/main.tsx` initializes LIFF, trades the ID token for a session, then renders.

```sh
pnpm dev
pnpm build
```

| Variable       | Default         |
| -------------- | --------------- |
| `VITE_LIFF_ID` | empty           |
| `VITE_API_URL` | the page origin |
